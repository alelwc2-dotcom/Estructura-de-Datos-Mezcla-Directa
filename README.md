# Práctica de Mezcla Directa (Ordenamiento Externo)

Implementación en Java de la lógica de intercalación de bloques (`intercalarBloques`) para el algoritmo de ordenamiento externo de **Mezcla Directa (Straight Merge)**, correspondiente a la Unidad 5 de la materia **Estructura de Datos (AED-1026)**.

## Requisitos Previos
- Java Development Kit (JDK) 17 o superior.
- IDE de desarrollo (IntelliJ IDEA, NetBeans o Eclipse).
- Git instalado para clonar el repositorio.
